# Cesium Geo Documentary

Produce videos through a resumable, evidence-backed pipeline. Keep facts, Cesium camera state, narration timing, overlays, and rendering separate.

## Enforce the premium map contract

- Administrative boundaries are always grounded. Build longitude/latitude positions without altitude, use `clampToGround: true`, terrain-classified fills without polygon height, and normally use a dark-underlay + semantic-main-line pair with adjacent `zIndex` values. If the selected-child underlay obscures its gold main line on a target GPU, hide only that selected underlay and retain the grounded gold main line. Never solve z-fighting with vertical offsets.
- Keep the parent overview fill transparent when a changing terrain-classified fill would rebuild Cesium ground batches or temporarily hide boundary lines. The parent outline carries hierarchy; reserve translucent fill motion for the actively selected child after the introduction.
- Use a clearly distinct but coordinated hierarchy palette: parent boundary deep wine red `#8B1E1E`, selected child gold `#FFD166`, and context children cool white `#E8F0F5`. Keep context main lines continuously visible after their initial reveal. Never place a black selected underlay above them; hide a selected overlay whenever its alpha is zero and suppress redundant per-frame material writes. The semantic color must remain readable through every handoff, so boundaries never flash black, blank, or white.
- Preserve every fill entity belonging to the same administrative feature. Cesium splits GeoJSON `MultiPolygon` features into multiple polygon entities, so aggregate fill color properties as an array keyed by the stable feature ID and update every property during selection transitions; never let repeated IDs overwrite earlier polygon parts.
- Reveal the parent with a fast grounded pen-draw: partition outer rings into roughly 56 sequential line segments and move a restrained pen-nib marker along the active segment. Draw once, remove the pen, and settle into a stable parent line; never retrace or float the pen/boundary above terrain.
- Keep the parent camera completely fixed while revealing the parent boundary and child hierarchy.
- Interpolate region travel with `Cesium.EllipsoidGeodesic`, quintic smoother-step position progress, and one continuous low-amplitude height arc. Adapt compact-tour flights to ground distance within about 3.2–5.4 seconds, avoid plateau-and-dive zooms, reserve about 0.9 seconds for arrival settle/hold, and lock the final camera exactly.
- Use Noto Sans SC for map/title/subtitle Chinese, Noto Serif SC for editorial display, Roboto Flex for Latin/numbers, and Roboto Mono for technical labels. Use 8% title tracking without glow.
- Split single-line subtitles by complete spoken phrases rather than raw character counts. Keep numbers with their classifiers and units, including combinations such as `43210人`, `3.2万亩`, `2025年`, and `3952.94亿元`; target a comfortably shorter line than the hard profile maximum and omit terminal or soft punctuation when it does not aid reading. Build a per-topic protected-phrase lexicon from the hierarchical title, parent and child place names, schools, foods, dialects, institutions, and recurring compound terms; use it during every split pass so names and words such as `革命老区`、`水产养殖`、`道路` never break between characters. After automated validation, read the entire cue sequence aloud. If a technically valid split still joins the start of a new phrase to the previous cue, use a validated profile-specific semantic override whose punctuation-normalized text exactly matches the narration.
- Use `zh-CN-YunyangNeural` around `-4%` by default, preserve pronunciation records, normalize formal narration near `-16 LUFS`, and keep music near 0.2. Formal generation must fail instead of silently falling back to Windows SAPI; SAPI is draft-only.
- Keep the connected Figma file, tokens, node map, implementation, and screenshots synchronized. The current design source is `https://www.figma.com/design/3o7fht8p72Aog2YnRzph5n` in `xu yaoting's team`.
- Treat portrait `1080×1920` / `9:16` as the primary social-video profile unless the user requests another master. Frame the parent boundary to occupy roughly 62%–75% of the safe composition without clipping, then use profile-specific child-camera scaling instead of reusing a landscape camera blindly.
- Replace decorative title lines with the location-neutral headset-globe mascot from `design/assets/geo-documentary-mark.png`: a pale-blue globe, mint land, deep-teal headset/microphone, cartography pencil, and map board inside a cream/mint circular badge. Preserve its friendly reference silhouette, transparent background, and small-size readability. Keep the visible title in the form `地理图说·{hierarchicalTopicName}` with no spaces around the middle dot.
- Keep the identity system and cover template location-neutral. Never hard-code the active topic, country, administrative level, satellite image, or sample locality into reusable component names, defaults, documentation, or asset backgrounds. Use replaceable fields such as `{topicName}`, `{regionPath}`, `{subtitle}`, and `{heroVisual}`; apply real locality content only to instances and production scenes.
- Treat a social-video cover as part of the finished video, not only a sidecar image. Export the production cover as PNG, show it for about 1.8–2.0 seconds at the beginning, and offset the map, narration, music, photos, captions, SRT, and VTT by the same duration.

## Run the workflow

1. Inspect available tools, project configuration, `.build-state/`, and existing artifacts.
2. Lock the active topic and output namespace. If the user switches region or level, stop all old-topic research and rendering immediately. Reuse only generic technical assets, and never overwrite a historical final video with the new topic.
3. Resolve the topic's geographic role and immediate-child level before research. Support `world → continent → country → admin1 → admin2 → admin3/locality → township/subdistrict → administrative village/community → natural village/settlement or rural area`. Separate the complete reliable boundary set from the narrated tour set: retain statutory children, forest farms, enclaves, islands, and other verified management units in `boundaryUnitIds`, while placing editorially toured direct children in `tourChildIds`. For a production described as a complete township or subdistrict tour, include every verified statutory immediate child in `tourChildIds`; keep forest farms and other supplemental management units boundary-only and normally unlabeled unless the editorial brief explicitly tours them. If an official immediate child lacks a reliable polygon, do not infer it and do not claim complete current-administration coverage. A parent-topic title requires spoken and visual coverage of every direct child selected for the tour, not merely displaying its boundary.
4. Establish boundary evidence before normalization. Prefer official GIS/WFS/GeoJSON/SHP, then credible public administrative data. Accept ESRI Shapefile only as a complete set with `.shp`, `.shx`, `.dbf`, and `.prj`; read `.cpg` when present, record every sidecar, detect the source CRS, reproject to EPSG:4326, preserve the originals, and fail on unresolved DBF encoding or private-use characters. Simplify a polygon coverage as one shared-edge-preserving set with `coverage_simplify(..., simplify_boundary=False)` only after `coverage_is_valid`; if the coverage is invalid, retain the unsimplified geometries and report the failure. Never simplify adjacent administrative polygons independently. Never use Voronoi, hand-drawn partitions, or center-point approximations as administrative boundaries.
5. Validate and normalize parent boundaries, child boundaries, and any narrated rivers, lakes, bays, mountains, ridges, coastlines, islands, roads, or settlements before scripting. Run coverage, control-point residual, topology, and visual overlay QA when boundaries are registered or digitized from an official planning map.
6. Build a cited research pack. Create a parent-topic introduction before child segments. Every applicable script should cover area, location and physical setting, population with year and population type, economy or livelihoods with year, historical sequence, representative culture, local customs, language/dialect, characteristic food or produce, ecology, and contemporary development. State census facts directly, for example `第七次人口普查，常住人口为……人`, without filler such as `口径下`. For township/subdistrict topics, also research notable local middle schools or equivalent secondary schools; include a school only when its identity, locality, significance, and real campus or activity image are verified. Distinguish town-specific facts from county or regional cultural context. Adapt fields at very small rural scales instead of inventing unavailable GDP or population data.
7. Generate professional but engaging narration, pronunciation data, and a storyboard whose sentences reference claims and visual evidence. Evoke familiarity through verified concrete local textures—roads, shorelines or fields, market rhythms, dialect sounds, seasonal work, kitchens, and exact foods—without inventing stock details such as school bells or a daily commute. Keep the emotion understated and observational; never instruct viewers to feel homesick or say `想家`、`回家` as an emotional prompt. Add pronunciation records for uncommon characters and local terms; pronounce `圩` as `xū`, including `市圩（xū）` in pronunciation guidance while keeping clean visible captions. Apply a phoneme or deterministic TTS-input override when a dictionary record alone does not force the intended reading, then audibly review every local or polyphonic term before release.
8. Prepare design tokens and component specifications. Set the visible title and production cover to `地理图说·{hierarchicalTopicName}`. Include the immediate parent for local administrative topics: township/subdistrict → `{county}{township}`, county/district → `{prefecture}{county}`, and continue the same rule upward when disambiguation is needed. Do not append editorial suffixes such as `全域与区县`. Keep reusable Figma masters on generic placeholders such as `地区名称` and `层级路径`; set real hierarchy text only on an instance.
9. Build a verified visual-evidence manifest. For every history, economy, culture, custom, language, food, school, ecology, or livelihood claim that benefits from imagery, obtain the most specific real local photograph, archive image, artifact, site, performance, craft, campus, or project image available. Prefer official/local originals and record the exact source URL, publisher/uploader, capture date when known, locality, subject, reuse status, and crop. Search-result thumbnails and short-video screenshots are discovery/evidence leads only; use a Douyin or other platform frame only after exact locality/subject verification and a documented reuse basis. Food imagery must show the exact named local dish or product; never substitute a similar generic dish. For a township production, target at least four distinct verified-real evidence subjects spanning history, economy/development, culture/custom, and a local middle school when the school and a publishable exact campus or activity image are both verified. If an exact real image cannot be verified, omit the image and keep the scene map-led. Never generate documentary-looking images of local food, schools, people, customs, buildings, or scenery.
10. Build a seekable parent introduction. Begin with satellite imagery, no child labels, and no child boundaries. Draw the grounded deep-wine parent outer boundary once with arc-length-paced segmented pen motion lasting about 3.0–3.4 seconds, using gentle quintic start/end easing; remove the pen, settle the parent line, then fade the complete reliable boundary-unit set in as one restrained group. Do not label every child in the overview. Keep the context main-line group stable after reveal and never let a transparent selected overlay or dark underlay depth-mask it.
11. Chain later child segments directly from the previous segment's exact final camera and highlight state. Use a deterministic velocity-continuous Cesium flight while the previous highlight and label fade out fully before the new highlight and label become visible; at most one child label may be visible in any rendered frame. Keep all noncurrent labels hidden. Keep heading and pitch stable, reduce apex lift, and never suddenly accelerate or zoom near the middle or arrival. Once arrived, hold the low-oblique camera unchanged through that child's narration. After the final toured child and only then, perform one 3.8–5.0 second quintic geodesic return to the exact first-map-frame parent camera, fade the child highlight/label, retain the settled hierarchy context, lock the camera, and begin the closing narration only after the lock.
12. Synchronize thematic visuals to word-level narration timing. When a named river, mountain, lake, bay, island, pass, road, or settlement is spoken, reveal its verified geometry and label on the map. When history or culture is spoken, show the verified image in the best collision-free negative-space position without covering the selected geography, feature label, top title, or subtitle. Keep one dominant photo at a time and use restrained entry/exit motion.
13. Generate narration audio, measure its real duration, and create sentence- and word-level captions.
14. Lock the formal imagery provider and quality contract. When the user requests satellite imagery, reject Natural Earth, OpenStreetMap, or other non-satellite/demo basemaps for formal output.
15. Capture Cesium frames with Playwright at fixed viewport, DPR, locale, timezone, and frame time. Prewarm the parent-boundary reveal, child-boundary fade-in, and physical-feature layers. Do not load every distant child flight into one startup tile queue. In sample mode, reload at each sampled flight start and capture its representative timestamps. In full sequential capture, warm each flight incrementally and, when required by the Cesium version or observed queue growth, reload the deterministic runtime at the flight start, at internal checkpoints no farther apart than about 0.5 seconds, and at the flight-end frame. Preserve the browser disk cache and restore the requested timestamp so camera and highlight continuity remain unchanged while Cesium's in-memory visible set resets. For fixed-state frame reuse after a flight, anchor to the first output frame strictly later than the fractional flight endpoint; never seek backward from that frame to the exact fractional endpoint, because the endpoint state boundary can force a hazardous Cesium visible-set rebuild even though the camera is already locked. Require consecutive settled render passes, visible tiles loaded, zero high/medium visible tile-queue work, and screenshot-stable endpoints. Record active and speculative low-priority offscreen requests diagnostically, but do not let them block an already byte-stable visible frame.
16. Compose standalone HyperFrames HTML files. In minimal clean-broadcast mode, show the embedded production cover, satellite map, hierarchical boundaries, selected-region highlight and current-only label, the headset-globe Logo + `地理图说·{hierarchicalTopicName}`, cue-synchronized feature layers, verified photos, and single-line subtitles. Use one evidence card at a time with a blurred backing field and contained/covered foreground as appropriate. Township videos should normally contain several verified real evidence cards spanning the strongest available history, economy, culture/custom, and school subjects; omit an exact subject rather than substitute an unverifiable image. Omit lower-left chapter titles, upper-right fact cards, source cards, failure wording, and duplicate provider strips unless explicitly requested. Generated visuals may illustrate abstract systems only and must be labelled `示意`; do not generate or simulate documentary local subjects.
17. Run typecheck, tests, HyperFrames lint/check, coverage-manifest checks, photo/feature evidence checks, snapshots, and visual review. Validate every final segment and every master join.
18. Preserve the requested geographic order, concatenate compatible segments with FFmpeg stream copy, write reports and stage state, and only then mark delivery complete.

## Use the bundled scripts

Run scripts from the project root. Prefer the CLI wrapper when it covers the task.

```powershell
pnpm geo-video doctor
python .agents/skills/cesium-geo-documentary/scripts/import-shapefile.py data/raw/example.shp --region-id <id> --region-name <name> --parent-id <parent-id> --id-field <id-field> --name-field <name-field> --expected-children <count>
pnpm geo-video validate-data --region <region-id>
pnpm geo-video capture --region <region-id> --profile landscape --encode
pnpm geo-video compose --region <region-id> --profile landscape
pnpm geo-video qa --region <region-id> --profile landscape --stage final
pnpm geo-video master --regions <id-1,id-2,...> --profile landscape --output renders/final/master.mp4
pnpm typecheck
pnpm test
```

Key deterministic scripts:

- `import-shapefile.py`: ingest a complete polygon SHP set, decode DBF attributes, detect and transform the source CRS, write parent/child GeoJSON, and emit a QA report and coverage manifest.
- `preprocess-boundaries.py` and `validate-geodata.py`: normalize and validate GeoJSON data.
- `build-research-pack.ts`, `generate-script.ts`, and `generate-storyboard.ts`: create cited content artifacts.
- `build-cesium-scenes.ts`: create seekable scene timelines.
- `build-child-tour.ts`: map sentence-level narration timing to complete direct-child camera flights, highlights, fixed holds, and coverage-manifest evidence.
- `capture-frames.ts`: perform Playwright frame capture and intermediate encoding.
- `build-smooth-map-video.ts`: legacy endpoint-crossfade utility; do not use it when continuous direct Cesium flights are required.
- `generate-narration.ts` and `generate-subtitles.py`: create measured audio and captions.
- `build-master-subtitles.py`: offset ordered standalone captions into master SRT/VTT deliverables.
- `compose-hyperframes.ts`: create responsive standalone compositions.
- `validate-delivery.ts`: validate draft or final video sets.
- `build-master-video.ts`: verify compatible segment streams, concatenate without re-encoding, extract a cover, and write master-video QA reports.

Use files under `templates/` when starting a new project or adding a region.

## Recover from failures

- Preserve successful stages and rerun only the failed region/profile.
- Keep missing tokens, unavailable services, rejected generated images, TTS fallback, capture timeouts, and data gaps in external diagnostics and manifests. Never narrate pipeline limitations, missing boundaries, unavailable touring, AI generation, or implementation failure to the audience; rewrite the editorial route naturally around verified material.
- Save diagnostics before aborting a failed frame or render.
- If Cesium Ion is unavailable, use an explicitly documented offline imagery/ellipsoid fallback; never claim terrain was rendered when it was not.
- If a formal satellite provider is unavailable, stop formal capture and preserve diagnostics. Do not silently fall back to Natural Earth, OpenStreetMap, a blurred screenshot, or generated imagery.
- If exact administrative boundaries cannot be acquired or registered reliably, stop the formal video. Do not substitute Voronoi cells, center-point partitions, hand-drawn lines, or visually plausible approximations.
- If only terrain is unavailable, keep the licensed satellite layer, use the ellipsoid, and disclose that real terrain was not rendered.
- If Figma is unavailable, deliver tokens, component specifications, node-map placeholders, and an import plan, but still render the required location-neutral production cover from the synchronized code/tokens and embed it in the final video.
- If ImageGen fails or clean-broadcast mode is active, use the planned verified real photo or a map-led scene. Never replace a required exact culture/history subject with a generic local image. Record locality, subject, resolution, license, and attribution in the external photo manifest.
- If formal premium TTS fails, stop the release build and preserve diagnostics. Windows SAPI may be used only with an explicit draft flag; record it as non-release-ready and regenerate all dependent timing before final delivery.
