# 地理图说 Premium Map System

Figma 设计源：[地理图说 Premium Map System](https://www.figma.com/design/3o7fht8p72Aog2YnRzph5n)

卫星影像始终是视觉主体。行政边界只承担层级表达：使用低透明度贴地底描与影像分离，再叠加父级、上下文、选中、上一层和补充管理单元的语义主线。任何行政边界都不得使用高度偏移、挤出、发光、脉冲或反复描线动画。

## 边界

- 父级：低透明度贴地底描 + 3.5 px 高级蔚蓝 `#2D9CDB` 主线；以约 3.0–3.4 秒、按边界弧长推进的一次缓和笔绘动画建立整体范围。
- 直接下级：阈值透明底描 + 2 px 冷白色 `#E8F0F5` 主线；使用自然淡入，禁止先黑后白。
- 当前选中：低透明度贴地底描 + 4 px 金色 `#FFD166` 主线，与父级有明显但协调的层级差异。
- 补充管理单元：1.5 px 低权重主线，默认不标注。
- GeoJSON 面使用地形分类贴地填充，不设置 `height`；折线使用 `clampToGround: true` 和相邻 `zIndex`。
- 生产实现只在语义主线透明度超过 `0.68` 后才引入暗底描，使用 `1.5` 次幂缓入并将最终底描比例限制为 `0.42`。绘线和子边界淡入阶段先呈现青色或冷白色，暗底描仅在主线已清楚时补足对比度。
- 父级概览填充取 `fillParent` 的 `0.09` 蔚蓝，作为**静态**贴地层一次性写入后不再改动，使行政区同时具备线与面的表达。可变透明度的填充会重建地面批次并导致主线丢失，因此禁止对其做逐帧动画；如有调整只改数值、不改逐帧行为。
- 线宽按合约取值：父级 `7 px` 底描 + `3.5 px` 主线、直接下级 `4 px` + `2 px`、选中 `8 px` + `4 px`、补充管理单元 `1.5 px`。这些值以各画幅的标称像素宽度为基准（横屏 1920、竖屏与方屏 1080），更高分辨率母版按比例放大，不在标称画幅上缩放。

## 底图调色

- 卫星影像来自不同提供商与拼接线，原始色调差异会让冷白下级边界在不同地区呈现不同对比度。生产渲染对底图统一调色，以亮度调整为主、饱和度仅轻微收敛，使边界层级对比可预期：亮度 `0.9`、对比 `1.05`、饱和度 `0.78`，`gamma` 与 `hue` 保持中性。影像始终是视觉主体，只统一影调、不做风格化，不模糊、不遮挡纹理。
- 调色值定义在 `apps/cesium-player/public/imagery-config.json` 的 `visual` 字段，运行时由 `/runtime-config.json` 下发，调整无需改动渲染代码。

## 镜头

- 父级边界和子级层级揭示期间，镜头完全静止。
- 行政区切换沿 WGS84 椭球大地线插值，位置使用五次平滑插值，高度使用一条连续低幅正弦弧线。
- 飞行时长根据地表距离在 3.2–5.4 秒之间自适应；采用五次平滑插值与单一低幅高度弧线，避免中途平台和抵达前突然俯冲，预留约 0.9 秒锁定画面。
- 开场不显示任何下级名称；某个下级首次巡游时才显示名称，此后一直保留。当前名称使用金色强化，已巡游名称使用克制冷白，未巡游名称继续隐藏。
- 完成全部下级巡游后，以 3.8–5.0 秒连续缓动回到父级初始视角，所有已巡游名称保持可见。回拉过程默认无旁白，禁止出现“巡游走完”“镜头回到”等制作语言。

## 字体与字幕

- 中文地图、标题、字幕：Noto Sans SC。
- 历史与编辑性展示：Noto Serif SC。
- 数字和拉丁字母：Roboto Flex。
- 技术标注：Roboto Mono。
- 标题：横屏 30 px、竖屏 32 px、字距 8%，无发光。
- 字幕：横屏 42 px、竖屏 44 px、方屏 40 px，圆角 10 px。
- 标题前导使用 `design/generated/midnight-globe-emblem.png` 的通用深蓝金色制图者地球徽记，圆形裁切并保留细金边；不再使用装饰横线、地图定位针或卡通耳机地球。标题固定为 `地理图说·{hierarchicalTopicName}`，乡镇带县名、县区带地级市名。

## 竖屏社交视频

- 首选输出为 1080×1920、9:16；父级行政区占安全画面的约 62%–75%，完整呈现且保留必要地理上下文。
- 左上标题、证据卡、底部字幕和平台按钮区互不遮挡；标题顶部安全边距 64 px，字幕至少高于底部 118 px。
- Figma 竖屏展示节点为 `51:43`；地图图像节点 `51:44`，实景证据图节点 `51:55`。
- 通用封面为深蓝金色亚洲地球、右侧日光与底部道路光轨构图。可见字段仅为 `地理图说`、`地区名称`、`看见边界，也看见土地上的生活` 和 `地理 · 人文 · 时代`；不显示层级路径、英文、期号或画幅比例标记。
- 封面生产底图为 `design/generated/midnight-globe-cover-background.png`，品牌徽记为 `design/generated/midnight-globe-emblem.png`；具体地区名称只写入生产实例。
- 通用封面可见品牌内容距离顶部不少于 64 px，底部页脚保留 120 px 安全边距。
- 每个生产实例既导出封面 PNG，也必须作为约 1.8–2.0 秒片头嵌入最终视频；地图、旁白、照片和字幕统一后移。

## 配音与声音

- 正式默认声线：`zh-CN-YunyangNeural`，推荐语速 `-4%`。
- 旁白按句号和段落形成自然停顿，保留发音记录和字幕文本映射。
- 正式 WAV 归一化至约 `-16 LUFS`，真峰值不高于 `-1.5 dBTP`。
- Windows SAPI 只允许显式草稿模式使用，正式模式不得静默回退。
- 环境音乐默认音量为 0.2，不能压住人声。

Figma 的 OPACITY 浮点变量使用 0–100；写入 Web/Cesium 时必须除以 100 转换为 0–1。
