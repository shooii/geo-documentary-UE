# Cesium 地理图说视频生产系统

本工程把行政区边界、研究资料、旁白、故事板、Cesium 镜头、艺术化复原素材、字幕与视频包装编排为可重复构建的地理纪录片视频。

当前首批范围为湛江市 9 个县级行政区：赤坎、霞山、坡头、麻章、遂溪、徐闻、廉江、雷州、吴川。

数据和艺术表达严格分离。行政区边界仅用于视频可视化，不作为测绘或法定界线依据；生成图片统一标注“AI 艺术化复原”。

## 天地图影像与逐场景注记

底图下拉框提供“天地图影像”。选中任意非封面场景后，可在右侧“场景编辑”中打开“天地图影像注记”；开关按场景保存，导出时只在这些场景的时间窗内叠加注记。Token 通过 `config/project.yaml` 的 `tianditu_token` 或环境变量 `TIANDITU_TOKEN` 配置。
